# HGhub 黄果短剧插件

面向 HGhub v0.0.3  **HPP 1.0.0-dev** 的单文件内容源，提供黄果短剧的浏览、搜索、详情、分集与 HLS 播放解析。

## 插件

| 项目     | 内容                                                          |
| -------- | ------------------------------------------------------------- |
| 展示名称 | 黄果短剧                                                      |
| 插件 ID  | `hghub.huangguo`                                              |
| 版本     | `1.0.1`                                                       |
| 插件文件 | [huanguo-source.js](./huanguo-source.js)                      |
| 导入清单 | [manifest.json](./manifest.json)                              |
| 内容标记 | `mature: true`，需在 HGhub 设置中开启成人内容显示后导入或启用 |

文件名保留为 `huanguo-source.js`；宿主以 `meta.id` 识别插件、以 `meta.name` 展示名称，不要求文件名与 ID 相同。

当前 ID 与早期的 `hghub.huanguo`、参考插件的 `huangguo` 不同，宿主会将它们视为不同插件，设置与存储不会自动迁移。

## 导入与订阅

### 订阅地址

在 HGhub **插件中心 → 导入与订阅** 粘贴下面任一 HTTPS 地址。清单中的插件路径为相对路径，会按清单最终 URL 解析。

| 列表     | 内容            | GitHub Raw                                                                    | jsDelivr                                                                |
| -------- | --------------- | ----------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| 黄果短剧 | 1个源（含成人） | `https://raw.githubusercontent.com/brady2037/hghub-plugin/main/manifest.json` | `https://cdn.jsdelivr.net/gh/brady2037/hghub-plugin@main/manifest.json` |

推荐先订 **jsDelivr**。成人列表需在设置里打开成人内容后再导入。若打不开，再改用 GitHub Raw 。

仓库首页：<https://github.com/brady2037/hghub-plugin>

### 导入步骤

1. 在 HGhub 设置中开启成人内容显示。
2. 打开 **插件中心 → 导入与订阅**，粘贴上表中的 HTTPS 地址。
3. 预览元信息，勾选 **黄果短剧**，检查 ID 为 `hghub.huangguo`、版本为 `1.0.1`，确认安装。
4. 确认插件状态为 **已就绪**。
5. 从首页、分类或搜索进入详情，选集播放。

订阅后可手动刷新列表。同 ID 的更高版本可用于更新，同版本覆盖可用于调试。更新时需同步修改源码 `meta.version` 与清单条目的 `version`，并保持两处 ID 一致。

### 本地导入

下载 `huanguo-source.js` 后，在 **插件中心 → 导入与订阅** 中选择该文件，检查元信息并确认安装。

Android 本地导入请直接选择 JS，不要选择本地 `manifest.json`：当前文件选择器不能读取同目录的相对路径插件文件。桌面端本地清单可使用相对路径。

## 支持能力

| 能力   | 当前实现                                                                 |
| ------ | ------------------------------------------------------------------------ |
| 首页   | 最新上线、热门榜单；最新上线支持查看更多                                 |
| 信息流 | 分页作品列表，入口为第 1 集                                              |
| 分类   | 全部短剧、AI 短剧、AI 漫剧；最新排序                                     |
| 搜索   | 关键词搜索与分页                                                         |
| 详情   | 作品信息、正片播放列表与分集                                             |
| 播放   | HLS 地址解析，提供上游返回的 H.264 / HEVC 候选并按宿主传入的编码偏好排序 |
| 评论   | 作品或指定分集的只读评论，过滤空正文和空回复                             |
| 线路   | 固定主站与两个发布页发现的镜像线路                                       |
| 封面   | 通过资源对象交由宿主执行 AES-128-CBC 解密                                |

当前未提供登录、评论发布、点赞或收藏写入、图文阅读能力。HLS 地址解析成功不等于所有设备均能解码播放。

## 线路与播放

- 默认使用插件内置的固定主站，可在插件详情页选择其他线路。
- 镜像通过两个内置发布页的发布脚本发现，仅解析受限字符串数组，不执行远程脚本。
- 镜像列表缓存一小时。单页失败不丢弃另一页的成功结果；均不可用且调用预算未耗尽时返回固定主站。取消或总预算耗尽会终止调用。
- 主播放接口为 `POST /api/videos/{id}/episodes/{ep}/playback`。仅在接口不支持或成功响应没有可识别地址时，回退 `GET /api/videos/{id}/play`。
- 认证、网络、取消、超时等错误直接传播。两种接口均未返回地址时报告 `UPSTREAM_CHANGED`。
- 分页状态编码在 JSON 游标中，不依赖插件运行时闭包保存页码；后续请求使用当前调用的剩余预算。
