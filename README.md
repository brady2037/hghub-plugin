# HGhub 黄果短剧插件

面向 HGhub HPP 1.0 的单文件内容源，提供黄果短剧的浏览、搜索、详情、分集与 HLS 播放解析。

协议当前处于 `1.0.0-dev` 阶段，使用前可查阅 [插件开发教程](../docs/developers/index.md)、[当前支持状态](../docs/developers/status.md)和[插件协议](../docs/plugin-protocol/README.md)。

## 插件

| 项目 | 内容 |
| --- | --- |
| 展示名称 | 黄果短剧 |
| 插件 ID | `hghub.huangguo` |
| 版本 | `1.0.1` |
| 插件文件 | [huanguo-source.js](./huanguo-source.js) |
| 导入清单 | [manifest.json](./manifest.json) |
| 内容标记 | `mature: true`，需在 HGhub 设置中开启成人内容显示后导入或启用 |

文件名保留为 `huanguo-source.js`；宿主以 `meta.id` 识别插件、以 `meta.name` 展示名称，不要求文件名与 ID 相同。

当前 ID 与早期的 `hghub.huanguo`、参考插件的 `huangguo` 不同，宿主会将它们视为不同插件，设置与存储不会自动迁移。

## 导入与订阅

### 本地导入

1. 打开 HGhub → **插件中心 → 导入与订阅**。
2. 选择本目录的 `huanguo-source.js`。
3. 检查预览名称为 **黄果短剧**、ID 为 `hghub.huangguo`、版本为 `1.0.1`，确认安装。
4. 确认插件状态为 **已就绪**，再从首页、分类或搜索进入作品详情。

Android 本地导入请直接选择 JS。当前 Android 文件选择器不能通过本地 `manifest.json` 读取同目录的相对路径插件文件。桌面端本地清单可使用相对路径。

### HTTPS 导入与订阅

本目录尚未配置可用的公开订阅地址。自行托管时，将 `manifest.json` 和 `huanguo-source.js` 放在同一 HTTPS 目录，然后在 HGhub 导入清单的 HTTPS 地址。清单中的 `url: "huanguo-source.js"` 会相对于清单最终地址解析；也可直接导入该 JS 的 HTTPS 地址。

同 ID 的更高版本可用于更新，同版本覆盖可用于调试。更新时需同步修改源码 `meta.version` 与清单条目的 `version`，并保持两处 ID 一致。

## 支持能力

| 能力 | 当前实现 |
| --- | --- |
| 首页 | 最新上线、热门榜单；最新上线支持查看更多 |
| 信息流 | 分页作品列表，入口为第 1 集 |
| 分类 | 全部短剧、AI 短剧、AI 漫剧；最新排序 |
| 搜索 | 关键词搜索与分页 |
| 详情 | 作品信息、正片播放列表与分集 |
| 播放 | HLS 地址解析，提供上游返回的 H.264 / HEVC 候选并按宿主传入的编码偏好排序 |
| 评论 | 作品或指定分集的只读评论，过滤空正文和空回复 |
| 线路 | 固定主站与两个发布页发现的镜像线路 |
| 封面 | 通过资源对象交由宿主执行 AES-128-CBC 解密 |

当前未提供登录、评论发布、点赞或收藏写入、图文阅读能力。HLS 地址解析成功不等于所有设备均能解码播放。

## 线路与播放

- 固定主站为 `https://huangguoai.com`；可在插件详情页选择其他线路。
- 镜像来自 `https://huangguoai.pages.dev/` 与 `https://huang-guo.pages.dev/` 的发布脚本，仅解析受限字符串数组，不执行远程脚本。
- 镜像列表缓存一小时。单页失败不丢弃另一页的成功结果；均不可用且调用预算未耗尽时返回固定主站。取消或总预算耗尽会终止调用。
- 主播放接口为 `POST /api/videos/{id}/episodes/{ep}/playback`。仅在接口不支持或成功响应没有可识别地址时，回退 `GET /api/videos/{id}/play`。
- 认证、网络、取消、超时等错误直接传播。两种接口均未返回地址时报告 `UPSTREAM_CHANGED`。
- 分页状态编码在 JSON 游标中，不依赖插件运行时闭包保存页码；后续请求使用当前调用的剩余预算。

## 验证

### 本地模拟测试

在 HGhub 仓库根目录执行，需要可用的 Node.js，无需额外安装测试依赖：

```powershell
node hghub-plugin/sim.test.mjs
```

测试文件为 [sim.test.mjs](./sim.test.mjs)，覆盖元信息与清单一致性、模块导入、能力对象、镜像解析与缓存、危险发布脚本拒绝、断网与局部超时、取消传播、分页、封面参数、详情和评论映射、播放回退、错误分类及串行请求预算。

当前全部 Node 模拟用例通过。此前已核对真实上游的搜索、分类、详情、评论和主播放响应，并验证封面解密样本；这些记录不代表上游始终可用。

### 应用内验收

以下项目尚未完成真实 QuickJS / HGhub 页面链路 / 原生设备验收，可按此顺序检查：

1. 单独导入 JS，确认名称、ID、版本及能力发现正确。
2. 重复导入同一文件，确认按同 ID 覆盖而非新增重复插件。
3. 打开首页、分类和搜索，翻页后重载插件，再使用已有游标继续请求。
4. 打开详情，确认封面、分集、评论正确，作品与分集 ID 保持上游身份。
5. 选择不同线路并播放，检查 HLS 请求和实际音画；分别验证 H.264 与 HEVC 样本。
6. 验证取消操作、不可用线路及超时反馈。
